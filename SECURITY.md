# Security

This is a static portfolio on GitHub Pages: no accounts, forms, cookies or
server code. It still matters if a page could be made to run someone
else's script, link somewhere it should not, or leak something it shipped.

To report a problem, use **Report a vulnerability** on this repository's
Security tab, which opens a private advisory. Please don't open a public
issue for it.

What is in place is recorded in `docs/SECURITY_BACKLOG.md`.
